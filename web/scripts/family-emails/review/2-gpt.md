## Part C
- Same skeleton every mail (problem, feature heading, steps, tip, button, "במייל הבא נדבר...") reads like a course; keep steps only where setup is real; bridges should connect to an action ("אחרי שיהיו לילד ארבע מילים במחברת, אפשר כבר להתחיל לשחק איתן.").
- Child on day 1: a 3-minute opening ritual (add a child, the CHILD picks the first word, search in Kids Mode, picture/example, one quiz, "זאת המילה הראשונה במחברת שלך"). "אל תבחרו בשבילו את המילה הראשונה. בקשו ממנו לבחור מילה אחת שהוא שמע היום ורוצה להבין." End: "זהו. המילה הראשונה כבר במחברת שלו. מחר נוסיף עוד אחת."
- Top 3: (1) day 0 = first success (metric: child searched first word); (2) first week around one loop: found -> understood -> saved -> practiced -> saw progress -> came back; first three mails: first word -> notebook/Kids Mode -> game; (3) behavior-triggered series (no child / no search / no game / streak / strong use / inactive: "היום מספיק שהילד יחפש מילה אחת.").
- Bottom line: rebuild the first 5 days: day 0 child + first word; 1 Kids Mode + full understanding; 2 first game; 4 notebook; 6 parent board. "פחות 'תראו כמה דברים בנינו', יותר 'הנה הדבר היחיד שכדאי לעשות היום'."
